# Demo Review Checklist

Use this checklist to walk through the review workflow in the Friday session.

- [ ] Open the pull request from `walkthrough-demo`
- [ ] Start a draft review
- [ ] Leave a review comment on a diff line
- [ ] Discard the draft review
- [ ] Confirm no pending review remains
- [ ] Append audit notes to the `Sandbox audit log` issue

## Talking points

- A draft review stays invisible to the PR author until submitted.
- Discarding a draft review removes the draft body and all draft comments.
- Always re-check the PR's reviews before declaring it clean.
